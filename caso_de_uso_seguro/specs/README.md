# Especificación SDD — Siniestro Fácil

Base documental: entrevistas del caso de uso Seguros y material metodológico ATLAS. La entrevista identifica el alcance inicial de siniestros vehiculares de daños materiales sin lesiones graves y exige mantener separadas las necesidades, decisiones y aspectos técnicos no confirmados.
