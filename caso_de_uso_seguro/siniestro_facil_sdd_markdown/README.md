## Regla aplicada
Solo se utilizaron hechos, necesidades, actores, objetos, restricciones y tensiones presentes en las entrevistas. Cuando la información no permite una definición, se registra como discrepancia/vacío pendiente.

## Autovalidación
El modelo físico no se completa con columnas, PK/FK, índices, motor o tecnología porque esos datos no aparecen en las entrevistas.
