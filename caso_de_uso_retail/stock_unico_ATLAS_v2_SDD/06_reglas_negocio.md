# Stock Único — NovaRetail

**Fuente:** entrevistas del caso `NovaRetail: Stock Único`  
**Método:** PROMPT ATLAS v2.0  
**Regla:** contenido sustentado exclusivamente en las entrevistas; los vacíos se mantienen como pendientes.

## Reglas confirmadas

| ID | Regla | Fuente |
|---|---|---|
| RN-001 | La disponibilidad debe distinguir stock utilizable de reservas/compromisos y considerar stock de seguridad; la fórmula varía por contexto. | Supply Chain P3 |
| RN-002 | Una unidad físicamente presente puede no ser apta para venta digital. | Supply Chain P3 |
| RN-003 | Una reserva es temporal y debe tener origen, cantidad, ubicación, creación, expiración y estado. | Supply Chain P4 |
| RN-004 | Una reserva puede confirmarse, liberarse, vencer o trasladarse según reglas controladas. | Supply Chain P4 |
| RN-005 | Un reintento de checkout no debe generar otra reserva. | Supply Chain P5 |
| RN-006 | El inventario en tránsito no aparece como disponible hasta recepción bajo el modelo actual. | Supply Chain P8 |
| RN-007 | No se reserva por visitar una página; la reserva ocurre al iniciar pago o confirmar pedido. | E-commerce P2 |
| RN-008 | Un pago aprobado no puede terminar sin pedido. | E-commerce P8 |
| RN-009 | La IA puede recomendar, pero no inventar existencias. | CEO P8 |
| RN-010 | Reserva y descuento de stock son transacciones controladas. | CEO P8 |
| RN-011 | El preparador no debe ver datos personales que no necesite. | E-commerce P7 |
